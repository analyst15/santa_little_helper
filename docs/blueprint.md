# **App Name**: Santa's Little Helper

## Core Features:

- List Creation: Create a new Secret Santa list with participant names and email addresses.
- Automated Matching: Randomly assign Secret Santa recipients while preventing self-gifting using generative AI to act as a "tool" to prevent any issues or exceptions in matching pairs. 
- Email Delivery: Send each participant an email with the name of their assigned recipient and any gift guidelines.  Also offer ability to resend emails if requested.
- Wish List Integration: Allow participants to create and share wish lists via URL in emails.
- Exclusion Rules: Specify rules to prevent certain people from being matched with each other.
- List Management: Allow list owners to view and manage the participation list.

## Style Guidelines:

- Primary color: Festive red (#E63946) to evoke the holiday spirit.
- Background color: Light, desaturated pink (#F1FAEE).
- Accent color: Analogous orange (#F4A261), used sparingly to draw attention to CTAs.
- Body and headline font: 'PT Sans', a friendly sans-serif font suitable for a wide audience
- Use simple, recognizable icons to enhance navigation and represent actions.
- Add subtle, holiday-themed animations (e.g., snowflakes, twinkling lights) on loading screens or successful actions to enhance the festive feel.
